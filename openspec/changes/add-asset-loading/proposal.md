# Proposal

## Why

M1 needs real content: the sandbox's Exosuit is a skinned glTF model with clips, the test ground and
showcases need textures and PBR materials, the audio change needs decoded sounds, and working on
content needs hot reload. So far scenes are built only from Lua vertex tables with flat colours.

## What Changes

- **Textures:** PNG and JPEG (stb_image) with mipmaps, `fk.gfx.texture(path)`; Lua meshes take UVs and
  draws take a `texture`.
- **glTF 2.0 models** (`.glb` and `.gltf` with separate or embedded buffers and images, via cgltf):
  triangle meshes, PBR metallic-roughness materials (base colour, metal/rough, normal and emission
  textures and factors, emissive strength), the node hierarchy with its rest pose, skins (joints,
  inverse bind matrices) and clips (translation, rotation, scale; linear, step, cubic spline).
  `fk.gfx.model(path)`, `model:clips()`, `model:nodes()`, `fk.gfx.draw(model, matrix)`.
- **One vertex layout** for scene meshes: position, colour, normal, UV, tangent, joints, weights.
  The G-buffer pass samples the material textures and applies normal maps.
- **Sounds:** WAV (SDL) and OGG Vorbis (stb_vorbis) decoded to float at 48 kHz, mono or stereo, up to
  60 s (music is streamed by `add-audio`).
- **Hot reload** on desktop debug builds: changed shaders rebuild the pipeline, changed scripts restart
  the game from `main.lua`, textures and models reload in place; a broken file keeps the old version.
- `require("game")` returns the table from `main.lua` (for scenarios and, later, mods).
- Placeholder art generated by `tools/models/make_models.py` (CC BY 4.0): the Exosuit, the materials
  showcase and the test-range ground texture.

**Out of scope:** skinning and clip playback (`add-animation-runtime`), alpha blending and masking
(rendered opaque), morph targets, sparse accessors, KTX2/Basis textures, mods in the VFS search path.

**Proving game test:** `tests/game/showcase_materials.lua` renders the materials showcase model on the
JPEG ground against a golden image.

## Capabilities

### New Capabilities
- `asset-loading`: textures, glTF models, sounds, file references inside `data/`, hot reload.

### Modified Capabilities
- `rendering`: materials gain textures and normal maps.
- `script-runtime`: `require("game")`.

## Impact

New `engine/src/assets/{image,model,sound,watch}.c`, `engine/src/script/lua_assets.c`; vendored cgltf
1.15 and stb_vorbis; the vertex format changes in `gl_gfx.c`, `frame.c`, `lua_gfx.c` and
`gbuffer.glsl`. New `data/models/`, `data/textures/`, `tools/models/`, `tests/fixtures/assets/`.
